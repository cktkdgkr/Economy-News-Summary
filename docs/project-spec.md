# 프로젝트 사양 — 경제 뉴스 요약 앱

## 1. 개요
매일 KST 07:00에 푸시 알림으로, 지난 하루의 글로벌 + 대한민국 핵심 경제 뉴스를 100자 내외 키워드 위주로 요약해 사용자에게 전달하는 안드로이드 네이티브 앱.

## 2. 플랫폼·언어
- 플랫폼: Android 네이티브.
- 최종 산출물: Google Play 스토어 배포용 **AAB(Android App Bundle)**.
- UI/요약문 언어: **한국어**.
- 권장 스택(planner가 최종 확정): **Kotlin + Jetpack Compose**, Coroutines/Flow, WorkManager, FCM(필요 시), Retrofit/OkHttp.

## 3. 핵심 사용자 시나리오
1. 사용자가 앱을 설치하고 알림 권한을 허용한다.
2. 매일 KST **07:00**에 알림이 도착한다.
3. 알림 내용: 전일(KST 00:00~24:00) 글로벌 + 한국 경제 뉴스의 **100자 내외 키워드 요약**.
4. 알림 탭 → 앱 내에서 더 자세한 요약(또는 원문 링크 목록)을 본다.

## 4. 데이터 소스
- 뉴스 소스: **빅카인즈** (https://www.bigkinds.or.kr/) 의 경제 카테고리.
- 접근 방식(공식 API vs 스크래핑): `docs/open-questions.md` 항목 #1, #2에서 researcher가 검증해야 결정 가능.

## 5. 요약 생성
- 수집한 기사 본문을 **LLM API**로 100자 내외 한국어 키워드 요약으로 압축.
- 길이 제약: **100자 ± 20** (planner 확정).
- 호출 위치: 백엔드 프록시 vs 온디바이스 — 보안·비용 트레이드오프는 `docs/open-questions.md` #4 참조.

## 6. 알림 트리거
- 매일 **KST 07:00**.
- 구현 옵션:
  - (a) 백엔드 cron → FCM 푸시 (정시성·중앙 제어 강점)
  - (b) 단말 WorkManager 주기 작업 + 로컬 알림 (백엔드 불필요)
- `docs/open-questions.md` #3에서 researcher가 비교.

## 7. 비기능 요구사항
- 정시성: KST 07:00 ± 5분 이내 알림 도달.
- 오프라인: 네트워크 실패 시 직전 요약 캐시 표시.
- 권한 최소: `INTERNET`, `POST_NOTIFICATIONS` 외 추가는 정당화 필요.
- 개인정보: 사용자 식별 데이터 수집은 기본적으로 하지 않음(필요 시 별도 합의).
- 접근성: 본문 폰트 스케일 대응.

## 8. 비범위(Non-goals)
- 사용자 계정/로그인.
- 실시간 뉴스 피드(앱은 1일 1회 요약에 집중).
- 다국어 UI(초기 한국어만).

## 9. 성공 기준
- KST 07:00에 안정적으로 알림이 도착한다(연속 7일 검증).
- 요약은 100자 내외에서 주제·핵심 키워드를 식별 가능한 수준.
- 릴리스 AAB가 Google Play 사전 검토(internal testing)에 통과.
