# Q2 — 빅카인즈 스크래핑 가능 여부 (이용약관 / robots.txt)

## 핵심 결론

빅카인즈 이용약관은 기사의 **전재·복제·배포를 명시적으로 금지**하며, 2025 뉴스빅데이터 해커톤 규정은 "뉴스 데이터 불법적 수집 행위 금지(크롤링 등)"를 명시한다. robots.txt는 직접 접근이 차단되어 본문 확인 불가. **스크래핑(분기 B)은 약관 위반 리스크가 커 보수적으로 사용 불가로 판단**한다.

## 근거

- 저작권 및 전재 금지: "빅카인즈에서 제공되는 모든 기사는 「저작권법」의 보호를 받으며, 이를 전재, 복제, 배포하는 행위를 금합니다."
  - 출처: 빅카인즈 페이지 공통 문구(FAQ 검색 결과 인용, 확인일 2026-05-21).
- 크롤링 명시 금지: "뉴스 데이터 불법적 수집 행위 금지(크롤링 등)"
  - 출처: 2025 뉴스빅데이터 해커톤 https://newsbigdata.kr/summary/summary.php (확인일 2026-05-21).
- robots.txt 직접 확인 실패: `https://www.bigkinds.or.kr/robots.txt` 요청 시 HTTP 403 Forbidden (확인일 2026-05-21). 본문 인용 불가.
- 한국 법원 참고 판례: 대법원 2022. 5. 12. 선고 2021도1533 — "서비스 제공자가 약관이나 기술적 조치 등으로 객관적으로 크롤링 제한을 드러냈는지 여부를 따져 정보통신망 침입 여부를 판단".
  - 출처: https://file.scourt.go.kr/dcboard/1727143941701_111221.pdf (확인일 2026-05-21).

## 권장안

- 스크래핑 분기(B)는 채택하지 않는다.
- 공식 API(분기 A) 승인 우선. 거부 시 다른 소스로 사양 변경 에스컬레이션.
- 만일 외부 원문 페이지에서 본문을 보강하려는 시도(Q12)도 동일 위험을 안으므로 **불허가 기본값**으로 두고 원문 링크 노출에 그친다.

## 잔여 불확실성

- robots.txt 실제 본문(서버 403로 확인 불가).
- 이용약관 전문 직접 확인 불가.
- 비상업·학술 목적 예외 조항 존재 여부.
