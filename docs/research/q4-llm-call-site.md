# Q4 — 요약 LLM 호출 위치 (백엔드 프록시 vs 온디바이스)

## 핵심 결론

API 키를 안드로이드 앱에 포함하면 역공학(APK 분석·네트워크 인터셉트·메모리 덤프)으로 추출될 수 있어 프로덕션 앱에는 부적합하다. 일 1회·기사 ~10건 규모면 LLM 비용은 월 $0.10 미만 수준이므로 비용 부담이 없다. **백엔드 프록시 권장**, 그리고 Q3의 백엔드(cron + FCM)와 자연스럽게 통합된다.

## 근거

- 모바일 앱 키 내장 위험: 보안 가이드 일반 원칙("Never ship API keys in mobile apps").
  - 출처: Kaiban LLM Proxy https://github.com/kaiban-ai/kaiban-llm-proxy 외 다수(확인일 2026-05-21).
- 비용(사실, 2026-05-21 기준):
  - Claude Haiku 4.5: 입력 $1.00 / 출력 $5.00 per MTok. (https://platform.claude.com/docs/en/about-claude/pricing)
  - Claude Sonnet 4.6: 입력 $3.00 / 출력 $15.00.
  - Gemini 2.5 Flash: 대략 입력 $0.15~0.30 / 출력 $0.60~1.00, 무료 티어 존재(추정치).
  - GPT-4o: 입력 ~$2.50 / 출력 ~$10.00.
- 예상 트래픽: 일 1회 다이제스트, 입력 ~2,000 토큰(메타 + 200자 본문 10건), 출력 ~200 토큰.
  - Haiku 4.5 일일 비용 ≈ $0.003, 월 ≈ $0.09.

## 비교

| 항목 | 백엔드 프록시 | 온디바이스 직접 호출 |
| --- | --- | --- |
| 키 보호 | 안전(키 서버 보관) | 위험(키 추출 가능) |
| 지연 | +1 hop | 직호출 |
| 비용 모니터링 | 중앙 집계 가능 | 사용자별 분산 |
| 사용자 키 부담 | 없음 | 사용자가 발급·입력 |
| Play 정책 | 문제 없음 | 키 노출 시 정책 위반 위험 |
| 오프라인 동작 | 불가(어차피 수집도 온라인) | 불가 |

## 권장안

- **백엔드 프록시 채택**, Q3 백엔드와 통합 — 별도 인프라 없이 동일 Functions 내에서 LLM 호출.
- MVP LLM: **Claude Haiku 4.5**(낮은 비용·안정성) 또는 **Gemini 2.5 Flash**(무료 티어로 초기 무비용 가능). 한국어 키워드 요약 품질 실측으로 최종 선택(Q9에 연계).
- 사용자에게 키를 받지 않는다. 키는 서버 환경변수/시크릿 매니저로 관리.

## 잔여 불확실성

- 한국어 100자 키워드 요약 품질 실측 비교(Claude vs Gemini).
- Gemini 무료 티어 한도 변경 가능성.
- 백엔드 운영 주체·인프라 결정(사양 외 — 에스컬레이션 사안).
