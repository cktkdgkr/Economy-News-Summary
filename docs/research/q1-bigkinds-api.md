# Q1 — 빅카인즈 공식 Open API 제공 여부

## 핵심 결론

빅카인즈는 공식 Open API를 제공한다(v4, `https://www.bigkinds.or.kr/v4/openApi/index.do`, 운영 주체: 한국언론진흥재단/KPF). 단, **키 발급은 심사·승인 방식**이며 일반 상업 앱에 대한 자동 발급 여부는 확인되지 않는다. 본문은 **최대 200자만** API로 제공되며 전문은 유료 서비스(뉴스토어)를 통해야 한다.

## 근거

- 공식 API 페이지 URL 존재: `https://www.bigkinds.or.kr/v4/openApi/index.do` (검색 결과로 URL 확인. 직접 접근 시 403 — 비로그인 차단으로 추정. 확인일 2026-05-21).
- 키 발급 절차: 사용신청서 작성 → 구글폼 제출(첨부 포함) → KPF 승인 → 이메일로 API 키·매뉴얼 수신.
  - 출처: 공주대 SW중심대학사업단 공지, https://swknu.kongju.ac.kr/community/noticedetail.do?seq=134 (확인일 2026-05-21).
- 본문 200자 제한: "빅카인즈에서는 뉴스저작권 보호를 위해 뉴스기사 다운로드 시 본문은 첫 200자까지만 제공하고 있으며, 본문 전체를 원하실 경우 ... 뉴스토어(www.newstore.or.kr)에서 유료상품을 구매하여 이용해 주시기 바랍니다."
  - 출처: 빅카인즈 FAQ (검색 결과 인용, 확인일 2026-05-21).
- 제공 기능(추정 정리): 뉴스 검색 결과 리스트, 특정 뉴스 본문(≤200자), 연관어 분석, 오늘의 이슈 등. `content` 필드 명시 요청 시 반환.
  - 출처: 빅카인즈 API 신청안내 https://www.newsbigdata.kr/filaboard/detail.php?c=n&v=v&s=45, `OpenAPI 사용자지침서 V1.5` 언급 (확인일 2026-05-21).
- 분당/일간 호출 한도: **확인 실패**(공식 약관·매뉴얼 PDF 직접 열람 불가).
- 일반 상업 앱(스토어 배포) 발급 허용 여부: 과거 공개 신청 경로는 SW사업·해커톤 참가자 위주. **확인 실패**.

## 권장안

- **옵션 1 (권장)**: 빅카인즈 공식 Open API 신청서 제출 → KPF 승인 → 분기 A(공식 API)로 진행. 본문이 200자로 제한되므로 LLM 입력은 `제목 + 리드 + 본문 일부(≤200자)` 조합.
- **옵션 2 (대안)**: 신청 거부 또는 상업 앱 불허 시, 다른 뉴스 소스(예: 공공데이터포털 뉴스 데이터셋, 언론사별 RSS, 네이버 검색 API)로 사양 변경 — **에스컬레이션 사안**.
- 스크래핑 분기는 Q2 결과상 비권장(별도 문서 참조).

## 잔여 불확실성

- 일간/분당 호출 쿼터 수치.
- 일반 상업 앱(Google Play 배포) 키 발급 가능 여부 및 별도 승인 조건.
- v4 개편 이후 변경된 엔드포인트·필드 상세.

> 참고: 본 문서는 법적 자문이 아니다. 약관·발급 조건은 KPF 안내를 따른다.
