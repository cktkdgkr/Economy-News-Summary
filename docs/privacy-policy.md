# 개인정보처리방침

**최종 수정일**: 2026-05-26

## 1. 수집하는 정보

본 앱(경제 뉴스 요약)은 다음 정보만 처리합니다:
- **FCM 토픽 구독**: 익명 기기 식별을 위해 Firebase Cloud Messaging 토픽("economy-news")에 구독합니다. 개별 FCM 토큰은 서버로 전송하지 않습니다.
- **로컬 캐시**: 수신된 뉴스 요약 데이터를 기기 내 Room 데이터베이스에 최대 30일간 저장합니다.

본 앱은 이름, 이메일, 위치, 연락처 등 개인 식별 정보를 수집하지 않습니다.

## 2. 정보 처리 목적

- 매일 경제 뉴스 요약 알림 전달

## 3. 제3자 서비스

본 앱은 다음 제3자 서비스를 사용합니다:
- **Firebase (Google)**: 푸시 알림(FCM) 및 서버 인프라
- **NewsData.io**: 뉴스 기사 수집 (서버 측에서만 접근, 앱에서 직접 호출하지 않음)
- **Google Gemini AI**: 뉴스 요약 생성 (서버 측에서만 접근). AI Studio 무료 티어 사용 시 입력/출력 데이터가 Google 제품 개선에 활용될 수 있습니다.

## 4. 데이터 보관

- 로컬 캐시: 30일 후 자동 삭제
- 서버(Firestore): 90일 TTL 후 자동 삭제
